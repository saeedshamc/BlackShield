# Sentinel

**Sentinel** یک پلتفرم امنیتی و حریم‌خصوصی اضطراری برای اندروید است. این برنامه کاملاً آفلاین کار می‌کند و به‌عنوان یک موتور اتوماسیون امنیتی محلی عمل می‌کند — بدون نیاز به سرور.

[English README](README.md)

## قابلیت‌ها

| ماژول | توضیح |
|--------|--------|
| موتور قوانین | خط لولهٔ خودکارسازی: محرک ← شرط ← اقدام |
| پروفایل‌های اضطراری | عادی، سفر، عبور از مرز، اضطراری، سفارشی |
| رمزهای اجبار | چند رمز با اقدامات دفاعی متفاوت |
| حالت فریب (Decoy) | گالری، مخاطبین، یادداشت، فایل و فعالیت جعلی |
| قفل برنامه | محافظت با PIN، رمز عبور و بیومتریک |
| دکمه پانیک | کاشی تنظیمات سریع، دکمه شناور، ترکیب دکمه‌های سخت‌افزاری |
| محرک‌های دکمه | پاور ×۵، ترکیب ولوم، نگه‌داشتن طولانی |
| گزارش رویدادها | تاریخچهٔ رمزنگاری‌شده و قابل جستجو |
| تشخیص نفوذ | تغییر سیم‌کارت، شکست باز کردن قفل، دستکاری دسترسی‌ها |
| سرویس دسترسی‌پذیری | پایش برنامه، وضعیت صفحه، اجرای قوانین |
| تنظیمات | پشتیبان‌گیری، رمزنگاری، تم، مدیریت پروفایل |

## شروع کار

### پیش‌نیازها

- Android Studio Ladybug (۲۰۲۴.۲) یا جدیدتر
- JDK 17
- Android SDK 35

### ساخت پروژه

پروژه را در Android Studio باز کنید و Gradle را همگام‌سازی کنید، یا از خط فرمان:

```bash
./gradlew assembleDebug
```

نصب روی دستگاه یا شبیه‌ساز (API 30+):

```bash
./gradlew installDebug
```

## راه‌اندازی اولیه

1. **تنظیم رمزها** — تنظیمات ← رمزهای اجبار (Duress)
2. **فعال‌سازی دسترسی‌پذیری** — برای پایش و قفل برنامه‌ها
3. **فعال‌سازی مدیر دستگاه** — برای تشخیص نفوذ
4. **ساخت قوانین** — داشبورد ← قوانین ← افزودن قانون
5. **پیکربندی پروفایل‌ها** — داشبورد ← پروفایل‌ها
6. **افزودن کاشی پانیک** — تنظیمات سریع ← ویرایش ← Sentinel Panic

## امنیت

- رمزنگاری AES-256-GCM با Android Keystore
- EncryptedSharedPreferences برای اعتبارنامه‌ها
- BiometricPrompt برای باز کردن قفل برنامه
- فیلدهای حساس Room در حالت ذخیره‌شده رمزنگاری می‌شوند
- فایل‌های پشتیبان قبل از خروجی گرفتن رمزنگاری می‌شوند
